# WP00.5 結果報告 — TTS 聞き比べ（VOICEVOX vs Qwen3-TTS 0.6B）

実施日: 2026-10-21 / 機体: 7560（standalone、ASR・LLM・VOICEVOX コンテナ稼働のまま）
ブランチ: `feature/wp005-tts-comparison` / アプリ本体（`server/`）は変更なし

## 結論（先に）

- **日本語は使える。ASR/LLM と同居もできる**（VRAM +2.4GB、ピーク 15.6GB / 16.4GB）
- **初回音声 約 345ms（< 500ms）は「疑似ストリーミング」での値**。公式 `qwen-tts` パッケージにはストリーミング出力 API がない（下記「つまずき 1」）
- **致命的なのは生成速度: RTF ≈ 1.0**（音声 1 秒の生成に約 1 秒かかる）。ストリーミング再生にすると途中で音が途切れる。全文合成を待つ方式だと 7〜11 秒かかり、VOICEVOX（0.8〜1.4 秒）より大幅に遅い
- 0.6B には **VoiceDesign モデルがない**（1.7B だけ）。`qwen3tts-0.6b-design` は計測していない

## 2. 計測結果（3 回の中央値。ウォームアップ 1 回は捨てた）

`tts-lab/out/results.csv` より。VOICEVOX は speaker_id=2、speedScale 1.0 / pitchScale 0.0 / intonationScale 1.0 / volumeScale 1.0（`server/src/config.py` の `VoicevoxConfig` と同じ値）。

|---|---:|---:|---:|---:|---:|---:|---:|
| ja-1 | 38 | 788 ms | 5.89 s | 338 ms | 7,234 ms | 7.52 s | 0.96 |
| ja-2 | 64 | 1,365 ms | 10.43 s | 349 ms | 10,554 ms | 10.88 s | 0.97 |
| ja-3 | 53 | 1,112 ms | 8.32 s | 346 ms | 9,648 ms | 9.52 s | 1.01 |
| ja-4 | 35 | 824 ms | 6.01 s | 343 ms | 7,256 ms | 6.96 s | 1.04 |
| ja-5 | 56 | 1,230 ms | 9.11 s | 348 ms | 9,988 ms | 10.24 s | 0.98 |
| en-3 | 187 | - | - | 351 ms | 11,217 ms | 10.08 s | 1.11 |
| en-5 | 146 | - | - | 342 ms | 10,513 ms | 11.52 s | 0.91 |
| zh-3 | 49 | - | - | 350 ms | 10,408 ms | 10.24 s | 1.02 |
| zh-5 | 42 | - | - | 347 ms | 8,589 ms | 10.40 s | 0.83 |

- 日本語 5 文の初回音声の中央値: **VOICEVOX 1,112 ms / Qwen 346 ms**
- VOICEVOX の RTF は 0.13〜0.14（CPU）。Qwen は約 1.0（GPU）
- 「Qwen 初回」の定義: 生成中に talker（コーデック生成器）の forward フックでコーデックフレームを受け取り、先頭 4 フレーム（12Hz なので約 0.33 秒分）が揃った時点で、その 4 フレームだけをデコードし終えるまでの時間。公式 README にある「97ms」は、DashScope 側か vLLM-Omni の将来の最適化での値と思われ、ローカルの `qwen-tts` では再現できない
- 3 回のばらつき: Qwen の初回は ±10ms と安定。全体はサンプリング（do_sample）で音声長が変わるため ±1 秒ほど揺れる
- VOICEVOX は日本語専用なので、en/zh は Qwen だけ

**同居できる（OOM なし）**。ただし GPU の計算を取り合うので遅くなる（補助スクリプトで測定。リポジトリには入れていない）:

| Qwen 未ロード | 461 ms | 338 ms |
| Qwen ロード済み・アイドル | 448 ms | 339 ms |
| Qwen 合成中 | **638 ms（+38%）** | **417 ms（+23%）** |

逆方向（LLM に負荷をかけ続けた状態での Qwen ja-3）: 初回 585 ms / 全体 17,273 ms（RTF 約 1.8）。

どちらもほぼ原文どおりに書き起こされた。違いが出たのは次の箇所だけ:

- ja-5「担当の課に」: Qwen は「担当のカニを」と書き起こされた

## 3. 導入でつまずいた点と解決

1. **公式パッケージにストリーミング出力がない**: `qwen-tts` 0.1.1 の `generate_*` には `non_streaming_mode` 引数があるが、docstring に "this option currently only simulates streaming text input ... rather than enabling true streaming input or streaming generation" とある。README も、vLLM-Omni はオフライン推論のみで、オンライン配信・ストリーミングは今後対応としている。→ 計測用に forward フックで先頭チャンクを取る方式にした（`compare.py` の `QwenEngine._on_step`）。アプリに入れるなら、生成ループを自前で書く必要がある
2. **0.6B に VoiceDesign がない**: README の表で確認した（1.7B だけ）。design 枠はスキップ。指示書が 0.6B 指定なので、1.7B は取得していない
3. **flash-attn は入れていない**: README は推奨しているが、PyPI にあるのはソースだけで、torch 2.14 / cu130 向けのビルド済み wheel はない。ビルドには nvcc（CUDA Toolkit）が要るが、この機体の PATH に nvcc はない（Toolkit の導入には sudo が要る見込み）。起動時に "flash-attn is not installed" の警告が出るが、sdpa で動作に問題はない。なお、遅さの主因は 1 フレームごとに走る 16 段のコードブック予測（Python ループ）と見られ、attention を差し替えても RTF ≈ 1 が大きく改善するかは不明
4. `pip install` は使わず、`uv add qwen-tts soundfile httpx` で問題なく入った（Python 3.12 / ドライバ 615 + torch cu130 で `torch.cuda.is_available() == True`）。torch と torchaudio のバージョンがずれているが、今回の範囲では問題なし
5. 実行中に `code_predictor_config is None. Initializing code_predictor model with default values` が毎回ログに出る。無害

## 4. 人間が決めること

- **イントネーションの評価**: `tts-lab/out/index.html` をブラウザで開いて聞き比べる（7560 上で。wav は git に入れていないので、別の機体で聞くなら `cd tts-lab && uv run python compare.py` で再生成する。約 6 分）。特に ja-4「能美」の読みと、Ono_Anna の声質（"Playful"）が役所のロビーに合うかを見てほしい
- **standalone で VRAM が足りない場合に LLM を 0.40 に下げるか**: 現状は下げなくても同居できる（残り約 800 MiB）。ただし YOLO11-pose（予備枠の想定用途）とは同時に載らない。両方載せるなら LLM を 0.40 に下げる（約 0.8GB 空く）判断が要る
- 判断の目安（指示書 2 章）との照合: 初回 < 500ms は疑似ストリーミングでなら満たす。同居も満たす。**ただし RTF ≈ 1.0 のため、ストリーミング再生は途中で途切れるおそれが高く、目安の前提（流れるように再生できる）が成り立たない**

## 5. 推奨案（Claude Code の判断）

WP01 では VOICEVOX を残す（日本語）。Qwen3-TTS 0.6B は、この機体（7560）ではストリーミングを実用にできる速度（RTF 1.0。安定して流すには 0.5 以下は欲しい）が出ず、全文待ちでは VOICEVOX より遅い。
代わりに、VOICEVOX を句読点で区切って文単位で先行合成する方式（アプリ側の改修）で、初回音声を 0.5 秒前後に縮めるのが近道。
Qwen3-TTS は英中韓の多言語枠として、vLLM-Omni のストリーミング対応か、site の T2／3660 での実行を待って再評価する。
