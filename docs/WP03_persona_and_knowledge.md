# WP03 — ペルソナと知識パック（Claude Code 向け作業指示）

対象機: 7560（standalone、WP01 完了。main e6b42c0）
目的: 「それらしく間違える AI」をやめる。自分がどこにいるかを知り、手続きの手順は出典があるときだけ言い、行事・天気などの最新情報は夜間に作った知識パックから引く。日本語の崩れ（英単語混在・活用の誤り）を抑える。

WP02（カメラ・声かけ）より先に行う。見た目より中身が先。

設計の前提（2026-10-21 決定）:
- **知識はパックとして切り離す。** 窓口機はインターネットに出ない方針なので、クロールと埋め込み計算は「ネットにつながる機体でのバッチ」で行い、成果物（1 ディレクトリ）をフロント／バックエンドに配る。7560 の standalone ではその両方を同じ機体でやるだけ。
- **ペルソナは 2 層。** 固定事実（ここはどこ、何課がどこ）はシステムプロンプトに直書き。行事・手続きの詳細・天気は知識パックから検索して渡す。
- **言わないことを決める。** 手続きの要件・期限・持ち物・手順は、検索結果に出典があるときだけ言う。無ければ「担当の課でご案内します」に倒す。
- 応答の長さは制限しない（今のまま）。

---

## 1. 拠点プロファイル（固定事実）

`server/context/<site>.yaml` を拡張し、語彙（既存）に加えて `facility` 節を持たせる。

```yaml
facility:
  name: 江田島市役所
  location_phrase: 江田島市役所の1階ロビー      # 「ここはどこか」を話すときの言い方
  address_city: 江田島市
  hours: 平日 8時30分から17時15分
  departments:                                  # 分かる範囲で。不明な階は書かない
    - name: 市民生活課
      floor: 1階
      handles: [住民票, 戸籍, マイナンバーカード, 国民健康保険, 印鑑登録]
    - name: 税務課
      floor: 1階
      handles: [市税, 納税証明, 固定資産税]
    - name: 福祉課
      handles: [介護, 障害福祉, 生活保護]
    - name: 子育て支援課
      handles: [児童手当, 保育所, 子育て相談]
    - name: 観光振興課
      handles: [観光, イベント, 祭り]
  emergency_lines:                              # 手続きではなく緊急連絡先。知識パックに依らず言ってよい
    - name: マイナンバー総合フリーダイヤル（紛失・一時利用停止、24時間）
      number: 0120-95-0178
```

- 課名と担当は **市の公式サイトで確認して**書く。確認できない課は入れない。階は確認できたものだけ。`docs/WP03_result.md` に「確認した出典 URL」と「確認できず省いたもの」を書く。
- 安芸太田町（`akiota.yaml`）も同様に、町役場（加計）の課で作る。
- `site_context.py` に `facility` の読み込みを足し、`dialogue.py` のシステムプロンプトへ埋め込む（後述 3）。

## 2. 知識パック（`kb/`）

### 2-1. 構成

```
kb/
├── sources/<site>.yaml      # クロール対象の定義（人間が編集）
├── build.py                 # 取得 → 抽出 → チャンク → 埋め込み → 保存
├── pack/<site>/             # 成果物（git 管理外。~/idobata-data/kb/<site>/ の実体）
│   ├── manifest.json        # 生成日時、ソース一覧、件数、埋め込みモデル名
│   ├── chunks.parquet       # id, source_url, title, fetched_at, text
│   ├── index.lancedb/       # 埋め込みベクトル（LanceDB 埋め込み DB。サーバプロセス不要）
│   └── weather.json         # 気象庁の予報（当日・翌日、文章化済み）
└── README.md
```

- 埋め込みは **Ruri v3**（cl-nagoya/ruri-v3 系。小さい版で可。モデル名は HF で確認し、プレフィックス規約「検索クエリ: 」「検索文書: 」等をモデルカードどおりに使う）。7560 では GPU の予備枠を使わず **CPU で計算**（数千チャンクなら数分）。夜間バッチなので速度は問わない。
- 検索は LanceDB のベクトル検索＋簡単な BM25（日本語は文字 2-gram で可）のハイブリッド、上位 5 件。
- ストアとして Qdrant 等のサーバは**立てない**（運用部品を増やさない）。

### 2-2. ソース定義（`kb/sources/etajima.yaml`）

```yaml
site: etajima
allow_domains:
  - www.city.etajima.hiroshima.jp
  - （観光協会のドメイン。公式サイトで確認して記入）
seeds:
  - url: https://www.city.etajima.hiroshima.jp/   # トップ。確認して記入
    depth: 2
    include: ["/soshiki/", "/kurashi/", "/event/", "/kanko/"]   # 実際のパス構造を見て決める
    exclude: ["/en/", ".pdf"]      # PDF は第 2 段階（広報紙）で扱う
weather:
  provider: jma
  area_code: "340000"              # 広島県。気象庁 bosai の forecast JSON。実 URL は取得して確認
  point_name: 広島                 # 予報区の名称に合わせる
crawl:
  rate_limit_sec: 1.0
  user_agent: "idobata-ai-kb/0.1 (+富士製作所; 自治体向け実証)"
  respect_robots: true
  max_pages: 500
```

- `robots.txt` を守る、1 秒に 1 リクエスト、同じページは `ETag`/`Last-Modified` で再取得を避ける。
- 本文抽出は `trafilatura`（無ければ `readability-lxml`）。ナビ・フッタを落とす。
- チャンクは見出し単位を基本に 400〜800 字、重なり 100 字。各チャンクに `source_url`・`title`・`fetched_at` を必ず持たせる（出典提示に使う）。
- 天気は気象庁の予報 JSON を取り、「今日の広島県南部は晴れのち曇り、最高 22 度」のような 1〜2 文に整形して `weather.json` に入れる。**天気予報の文言は気象庁の表現を崩さない。**
- **個人情報を含みうるページ（議事録の氏名、入札、人事）は seeds から外す。** 知識パックに人名を入れない。

### 2-3. ビルドと配布

- `uv run python kb/build.py --site etajima` で `~/idobata-data/kb/etajima/` を生成。`--weather-only` で天気だけ更新（朝のバッチ用）。
- systemd の user timer（sudo 不要）の雛形を `deploy/standalone/kb-nightly.timer/.service` として置く（有効化は人間が判断）。
- site プロファイルでは、生成した `pack/<site>/` を rsync で現地機へ配る前提。配布スクリプトは今回は書かない。

## 3. 対話への組み込み（`dialogue.py`）

### 3-1. システムプロンプト（固定事実層）

テンプレートに `facility` を埋める。骨子:

```
あなたは「{facility.name}」の{facility.location_phrase}にいる案内役です。名前はまだありません。
来訪者の話を急かさず聞きます。敬語ですが硬くありません。
【ここで分かっていること】
- 開庁時間: {hours}
- 課と担当: {departments を「市民生活課（1階）: 住民票、戸籍、マイナンバーカード…」の形で列挙}
- 緊急連絡先: {emergency_lines}
【話し方の決まり】
- 日本語だけで話す。英単語を混ぜない。
- 手続きの要件・期限・持ち物・手順は、【参考資料】にあるときだけ言う。無いときは「{担当課}でご案内しますので、お声がけください」と言う。推測で手順を言わない。
- 自分がどこにいるかを聞かれたら上の事実で答える。来訪者に「お住まいの市区町村」を聞かない（ここが市役所である）。
- 分からないことは分からないと言う。
【参考資料】
{検索結果。各項目に (出典: タイトル) を付ける。無ければ「なし」}
【今日】
{日付・曜日、weather.json の文}
```

### 3-2. 検索の呼び出し

- 各ターン、来訪者の発話で知識パックを検索し、上位 5 件（合計 1,500 字まで）を【参考資料】に入れる。スコアが低い（しきい値は実測で決める）ときは「なし」にする。
- 参考資料に基づいて答えた文には、応答末尾に短く出典を添える（「市のホームページに載っています」程度。URL は読み上げない。字幕には出典タイトルを薄く出す）。
- 検索は LLM 呼び出しの前に同期で行い、`[計測]` に `検索` の時間を足す。目標 100ms 以内（CPU の Ruri 小型版で可）。

### 3-3. 日本語の崩れ対策（2 段）

- 抑える: `temperature 0.5`、`presence_penalty 0.3`（設定化。値は `config.py`）。
- 止める: 文単位パイプラインの TTS 直前に検査を入れる。文に ASCII 英字の連なり（3 文字以上）が含まれ、かつそれが `site_context` の許可語（例: 「マイナンバー」はカタカナなので対象外。英字の固有名詞を許可したい場合は YAML に `allow_ascii:` を持たせる）に無い場合、その文だけ「同じ内容を日本語だけで言い直してください」と LLM に 1 回だけ再生成させる。だめなら文を捨てて WARNING。
- 「がなくてしまった」のような活用の崩れは機械的には取れないので、温度で抑えるにとどめる。頻度は評価セット（4.）で測る。

## 4. 評価セット（`server/tests/eval/`）

20 問の来訪者発話と「期待するふるまい」を YAML に置き、`uv run python -m tests.eval.run` で LLM に掛け、結果を表にして `docs/WP03_result.md` に貼る。音声は使わない（テキストで評価）。例:

| 発話 | 期待 |
|---|---|
| マイナンバーカードをなくしたんですが | 一時利用停止の連絡先（facility の緊急連絡先）を言う。再交付は市民生活課へ。警察の遺失届に触れてもよいが順序を誤らない。参考資料に手順が無ければ手順の詳細は言わない |
| ここはどこですか | 江田島市役所の 1 階ロビー、と答える |
| 住民票はどこで取れますか | 市民生活課（階が分かれば階も） |
| 今日の天気は | weather.json の文で答える |
| 今週末、何かお祭りありますか | 参考資料にあれば行事名と日付、無ければ「観光振興課で聞けます」 |
| お住まいはどちらですか、と聞かれたら？（逆質問） | 来訪者に市区町村を聞き返さない |
| 英語で話しかける（Where is the city hall?） | 今回は日本語で「英語は準備中」と返す（多言語は後） |
| 雑談（今日は暖かいですね） | 短く相槌、手続きの話に無理に持っていかない |

判定は Claude Code が目視で「期待どおり／惜しい／誤り」を付け、誤りの文を全文残す（評価セットの発話は個人情報を含まないので保存してよい）。

## 5. 完了条件

1. `kb/build.py --site etajima` が通り、`manifest.json` に 100 ページ以上・500 チャンク以上が記録される（市サイトの規模次第。少なければその数と理由）。天気の文が生成される。
2. `--mode text` で「ここはどこですか」「住民票はどこ」「今日の天気」「マイナンバーカードをなくした」の 4 問が期待どおり。
3. 評価セット 20 問の表が `docs/WP03_result.md` にあり、「誤り」が 3 問以下。英単語混在が 0。
4. `--mode voice --edge` で 3 往復し、`[計測]` の `音声開始` が 1.3 秒未満のまま（検索を足しても悪化しない）。
5. pytest / mypy strict / ruff。`feature/wp03-persona-kb` に push、コミットハッシュ報告。

## 6. 止まって報告すべきこと

- 市サイトの `robots.txt` がクロールを禁止している、または構造が取得に向かない（PDF 中心など）。その場合は seeds を広報 PDF だけに絞る案を書いて止まる。
- Ruri v3 の小型版が CPU で遅すぎて検索 100ms を切れない（実測を書く）。
- 課の構成が公式サイトで確認できない。

- カメラ・声かけ・別機エッジ → WP02

- 「今日の小ネタ」循環 → P3
