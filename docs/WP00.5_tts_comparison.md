# WP00.5 — TTS 聞き比べ（VOICEVOX vs Qwen3-TTS 0.6B）

対象機: 7560（standalone、WP00 完了状態、ASR/LLM/VOICEVOX 稼働中）
目的: VOICEVOX を Qwen3-TTS に置き換えるかを決める材料を集める。**この WP ではアプリ本体（main.py / tts_client.py）を変更しない。** 計測用スクリプトと結果文書だけを作る。

背景（WP00 の実測）: 発話終了→音声開始 1.95〜2.89 秒のうち ASR 0.2 秒・LLM 0.7〜0.9 秒で、残り 1〜2 秒が VOICEVOX の全文合成待ち。イントネーションも読み上げ調。Qwen3-TTS はストリーミング（初回パケット約 97ms）・多言語（日英中韓を含む 10 言語）・声の設計と複製・Apache 2.0 で、採用できれば TTS を 1 エンジンに寄せられる（越語のみ別）。

### 1-1. Qwen3-TTS 0.6B の導入（アプリとは別の環境）

- `tts-lab/` ディレクトリを作り、そこに uv で独立した Python 3.12 環境を作る（`server/` の環境を汚さない）。
- `Qwen/Qwen3-TTS` の公式リポジトリ（GitHub QwenLM/Qwen3-TTS）の README に従い、pip パッケージ（`qwen-tts` 系）を `uv add` で入れる。モデルは **0.6B** を使う。公式の 0.6B には Base（複製・設計向け）と CustomVoice（プリセット話者）系があるので、両方あれば両方、無ければある方を取る。モデル名は README で確認し、推測しない。
- 日本語対応は公式 README の言語一覧で確認し、`docs/WP00.5_result.md` に一覧をそのまま転記する（Japanese が無ければ 1-6 で止まる）。
- GPU で動かす。VRAM 実使用量（モデルロード直後、合成中のピーク）を `nvidia-smi --query-gpu=memory.used --format=csv -l 1` で記録する。ASR/LLM コンテナは**止めない**（同居できるかを見るのが目的）。OOM になったら、その時点の数値を記録して 1-6 へ。

### 1-2. 評価用テキスト（5 文、日本語）

WP00 の実会話と井戸端AIの用途に合わせた 5 文を `tts-lab/sentences_ja.txt` に置く。

1. こんにちは。そうですね、今日はちょっと肌寒いです。お体に異変はありませんか？
2. お疲れ様です。体調悪そうですね。しっかり休んで、体を温めてくださいね。何かお手伝いできることがあれば、いつでも言ってくださいよ。
3. 国民健康保険の更新でしたら、二階の市民課が担当です。書類をお持ちでしたら、どこに書くか一緒に見ましょうか。
4. 今週の土曜日は、能美の海辺で秋祭りがありますよ。お時間があれば、ぜひ。
5. ご相談の内容、担当の課にお伝えしておきましょうか。お名前と、ご都合のよい連絡方法を教えていただければ大丈夫です。

英語・中国語の確認用に、3 と 5 の英訳・中訳も `sentences_en.txt`、`sentences_zh.txt` として置く（翻訳は Claude Code が行ってよい）。

### 1-3. 計測スクリプト `tts-lab/compare.py`

各エンジン・各文について、以下を計測し CSV（`tts-lab/out/results.csv`）に書く。音声は `tts-lab/out/<engine>/<lang>_<n>.wav` に保存する（人間が聞き比べる用。**評価用の合成音声なので保存してよい**）。

| 列 | 内容 |
|---|---|
| engine | voicevox / qwen3tts-0.6b |
| lang, n | 言語と文番号 |
| chars | 文字数 |
| t_first_audio_ms | リクエスト送出→最初の音声チャンク受信まで。VOICEVOX は `audio_query`＋`synthesis` 完了まで（ストリーミング不可のため合成完了＝初回音声）。Qwen3-TTS はストリーミング API で最初のチャンク受信時刻 |
| t_total_ms | 全音声の受信完了まで |
| audio_sec | 生成音声の長さ |
| rtf | t_total / audio_sec |
| vram_peak_mb | 合成中の GPU メモリピーク（Qwen3-TTS のみ） |

- VOICEVOX は WP00 と同じ speaker_id、同じ speedScale 等で合成する（`server/src/tts_client.py` の設定値を読んで合わせる。コードは複製せず、HTTP を直接叩いてよい）。
- Qwen3-TTS は、プリセット話者があれば日本語向けの話者を 1 つ選ぶ。**声の設計（テキスト指示から声を作る）が使えるなら**、「40 代くらいの落ち着いた女性、役所のロビーで話を聞いてくれる人、ゆっくりめ、温かい」で 1 声作り、同じ 5 文を追加で合成する（engine=`qwen3tts-0.6b-design`）。複製機能は今回使わない（声のサンプルの権利処理が未定のため）。
- 各文を 3 回ずつ合成し、計測値は中央値を取る（初回のウォームアップは別に 1 回捨てる）。
