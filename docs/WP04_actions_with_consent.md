# WP04 — 同意を取ってから外に働きかける（調べる・つなぐ・覚えておく）＋相槌

対象機: 7560（standalone、WP03 完了。main 2acb538）
目的: 井戸端AI が「聞いて答える」だけでなく、会話の中で **提案 → 同意 → 行為** を行えるようにする。行為は 3 種類で、すべて同じ型（提案文 → 来訪者の返事の判定 → 実行 → 結果の報告）で作る。あわせて、聞き取り確定直後の**相槌**で体感の待ちを消す。

前提の決定（2026-10-21）:
- 参考資料は 1,000 字のまま。音声開始が時々 1.3〜1.5 秒になるのは受け入れ、相槌で体感を補う。
- 会話・音声・映像は外に出さない。「調べる」で外に出すのは**検索語だけ**。一般の検索エンジンは市ごとの設定で既定 OFF。
- 紹介状は本人が「伝えて」と言ったときだけ作る。氏名・連絡先は本人が言った場合のみ。
- アバターの呼び名は設定値 `IDOBATA_AVATAR_NAME`（既定「いどちゃん」、仮。市民公募で決める前提）。

WP04 は **A → B → C** の順。A と B を終えて push してから C。C は時間が無ければ着手しない。

---

## A. 相槌と行為の枠組み

### A-1. 相槌（backchannel）

- ASR の確定テキストが出た瞬間（LLM を呼ぶ前）に、短い相槌を 1 つ再生する。候補は `server/context/backchannel.yaml` に置き、簡単な規則で選ぶ：
  - 質問形（「〜ですか」「〜どこ」「いつ」）→「はい」「ええと」「ちょっと見ますね」
  - 打ち明け・不調（「つらい」「困って」「しんどい」）→「ええ」「そうでしたか」（間を長めに）
  - 雑談（天気・季節・挨拶）→「ええ」「ほんとに」
  - 短い返事（「うん」「はい」「そう」）→ 相槌なし
- 相槌は VOICEVOX で起動時に**事前合成してキャッシュ**（数十個）。再生は本応答の 1 文目と同じ再生キューに積み、間に 0.3 秒の無音を置く。本応答の 1 文目が相槌と同じ語で始まる場合（「はい、…」）は、その文頭を落とす。
- SpeechGate は相槌の再生開始で mute（今と同じ扱い）。
- `[計測]` に `相槌開始` を足す。目標：発話終了から 0.5 秒以内。

### A-2. 行為の枠組み（`actions.py`）

- 状態：`LISTEN`（通常の対話）→ `PROPOSED(action)`（提案文を言った直後）→ `CONFIRMED` / `DECLINED` → `ACTING` → `LISTEN`。既存の待機タイムアウト（90 秒）で `LISTEN` に戻る。
- 提案は LLM の応答文の中に埋め込ませず、**行為ごとの定型文**で言う（テンプレートは YAML）。例：「よければ、ちょっと調べてみましょうか？」「このこと、担当の課に伝えておきましょうか？」。LLM には「提案してよい状況かどうか」だけを判定させる（応答の末尾に `<propose:lookup>` のようなタグを出させ、読み上げ前に除去する）。
- 返事の判定は LLM を使わず規則で：「はい／うん／お願い／そう／ええ／頼む」→ 同意、「いい／いらない／大丈夫／いや／結構」→ 辞退、それ以外→もう一度だけ聞き直し、だめなら辞退扱い。判定語は YAML。
- `PROPOSED` の間は、来訪者の発話を通常の対話に流さない（同意判定だけ）。
- 実行中は状態 `thinking` をエッジに送り、「少々お待ちくださいね」を言う。結果は 1〜3 文で報告し、`LISTEN` に戻る。

### A-3. 調べる（lookup）

- 対象は `kb/sources/<site>.yaml` の許可ドメインのみ。各ソースに `lookup:` を持たせ、サイト内検索の URL テンプレート（例 `https://.../search?q={q}`）か一覧ページ（お知らせ・イベント一覧）を指定する。
- 検索語は LLM に作らせる（「来訪者の発話から、場所・行事・手続きの名前だけを 2〜4 語で。本人の事情・氏名・体調・家族の話は含めない」）。作った検索語は読み上げ前に ASCII 英字検査と同じ安全装置を通し、**ログには出さない**。
- 取得は Playwright 不要の静的取得を優先、`render: playwright` のソースはそれで。合計 5 秒で打ち切る。
- 見つかったら、本文を知識パックと同じチャンク規則で切り、その場で参考資料として LLM に渡して答える。見つからなければ「今日の夜に調べておきますね」と言い、検索語を `~/idobata-data/kb/<site>/seed_queue.jsonl` に積む（翌朝のビルドが `daily` の区画に加えて取りに行く）。
- 一般の検索エンジン（`lookup.web_search.enabled`）は既定 `false`。`true` のときだけ、検索語を DuckDuckGo の HTML 版（または設定した URL）に投げ、上位 3 件の許可ドメイン外ページも読む。**今回は実装するが既定 OFF のまま、評価では使わない。**

### A-4. 完了条件（A）

- `--mode voice --edge` で、「今週末、道の駅で何かやってますか」→ 相槌 →（知識パックに無ければ）「調べてみましょうか？」→「うん」→ 取得 → 回答、が通る。見つからない場合は「今夜調べておきます」と `seed_queue.jsonl` に 1 行入る。
- `相槌開始` が 3 往復とも 0.5 秒以内。相槌と本応答の間が不自然に空かない（人間が耳で確認）。
- 「いらない」で辞退したとき、通常の対話に戻る。
- pytest / mypy / ruff。`feature/wp04-actions` に push。

## B. つなぐ（紹介状）と職員パネル

### B-1. 紹介状

- 提案条件（LLM が `<propose:refer>` を出す状況）：手続きの相談で担当課が特定できるとき、困りごとの打ち明けで「相談先がある」と判断できるとき（子育て・介護・生活の困窮など）。雑談では出さない。
- 同意後に LLM で構造化：
  ```json
  {"id":"...","site":"etajima","created_at":"...","department":"市民課",
   "category":"手続き|相談|意見|その他","summary":"本人の言葉を 2〜3 文で要約",
   "urgency":"急ぐ|通常","contact_pref":"窓口で待つ|電話|後日来庁|未定",
   "name":null,"phone":null,"language":"ja","edge_id":"..."}
  ```
  `name`/`phone` は本人が言った場合のみ。言っていなければ聞かない（「お名前はおっしゃらなくても大丈夫です」）。電話番号は復唱して確認。
- 保存先：`~/idobata-data/referrals/<site>/<date>/<id>.json`。**ここだけが会話由来で残るデータ**。保持期間は設定（既定 30 日）で、起動時に古いものを消す。
- 来訪者への報告：「市民課に伝えておきました。窓口でお名前をおっしゃるか、しばらくお待ちください」。番号札のような**受付番号（4 桁）**を言い、字幕にも出す。
- 安芸太田：`kintone`/サイボウズ取り込み用に、同じ内容を 1 日 1 ファイルの CSV（UTF-8 BOM、ヘッダ固定）にも書き出す（`referrals/<site>/<date>.csv`）。

### B-2. 職員パネル（最小）

- `edge_server.py` に `/staff/` を足す（同じ FastAPI、同じポート 8080。**LAN 内のみ**、簡易 Basic 認証、パスワードは `.env`）。
- 一覧：未対応／対応中／完了、受付番号・課・要約・急ぎ・連絡方法・時刻。クリックで状態を変える。更新は 10 秒ごとのポーリングで可。
- 「今日の状況」：来訪者数（セッション数）・紹介状数・言語別。**個人を特定する情報は出さない**（要約は本人の言葉の要約なので、職員が読む前提で出す）。
- 装飾は最小。縦置きサイネージではなく職員の PC で見る前提。

### B-3. 完了条件（B）

- 「国保の切り替えで聞きたいことがあって」→（応答）→「担当の課に伝えておきましょうか？」→「お願い」→ 保存 → 受付番号の読み上げ、が通る。`/staff/` に表示され、状態を変えられる。
- 氏名を言わなかった場合に聞き返さないこと、電話番号を言った場合に復唱することを確認。
- 保持期間を 0 日にして起動すると前日の紹介状が消えること。
- pytest / mypy / ruff、push。

## C. 覚えておく（今日の小ネタ）※時間があれば

- 雑談の中で「それ、みんなに教えてあげてもいい？」と提案する条件：行事・季節・畑・魚・天気のような話題で、個人の事情を含まないと LLM が判定したとき（`<propose:share>`）。
- 同意後、LLM で**匿名の一言**（20〜40 字。人名・住所・家族構成・体調を含まない）に書き直し、再度「こんな感じで伝えますね：〇〇。いいですか？」と確認してから `~/idobata-data/tidbits/<site>.jsonl` に積む（保持 7 日）。
- 次の来訪者との雑談で、1 回の会話に 1 つまで「さっき来た方が、〇〇って言ってましたよ」と使う。
- 職員パネルから削除できる。
