# WP12 — 会話音声の保存（7 日）と管理者ページでの再生（Claude Code 向け作業指示）

対象機: 7560（standalone）。ブランチ `feature/wp12-audio`（WP11 のマージ後に main から切る）。
目的: 案内役が聞き取った内容が妥当だったか（説明の不備・誤り・聞き取れなかった発話）を人が音声で確かめられるようにする。
文字記録（WP06）に、来訪者の発話区間の音声を並べて保存し、管理者ページで行ごとに再生する。

前提の決定（2026-10-24、Norio）:
- **既定は保存する**（7 日）。`IDOBATA_AUDIO_RETENTION_DAYS=0` で保存しない（従来どおり）。
- 保存するのは**来訪者の発話区間だけ**（VAD で切って ASR に渡した区間。案内役の応答音声は VOICEVOX で再合成できるので保存しない）。
- 紹介状の聞き取り（氏名・地区・電話番号）の区間も**保存する**（アウトリーチが必要なときに正しく聞き取れたかを確かめるため。
  文字記録は従来どおり伏せたまま。音声は管理者ロールだけが聞ける）。テスト運用の間はこの方針。本番前に掲示文言と合わせて見直す。
- これにより「音声は録音しない」の約束は「文字と音声の記録を 7 日間、庁内の管理者だけが品質確認のために確認し、その後消去する」に変わる。
  CLAUDE.md の禁止事項の例外、掲示文言の案（市への確認事項 5）、構想メモを**同じコミットで**合わせる。

---

## A. 保存

- `AudioRetentionConfig`（config.py）: `retention_days: int = 7`（`IDOBATA_AUDIO_RETENTION_DAYS`）、`sample_rate=16000`、`format="wav"`、
  `include_intake=True`（紹介状の聞き取りの区間も保存。False で WP06 と同じ境界で外す）。`.env.example` に 1 行足す（.env との差分を報告）。
- 置き場: `~/idobata-data/transcripts/<site>/<date>/audio/<utterance_id>.wav`（16kHz モノラル 16bit。VAD の前後マージンを含む、ASR に渡したのと同じ波形）。
  文字記録の行（jsonl）に `audio: "<date>/audio/<utterance_id>.wav"` を足す。utterance_id は文字記録の行 id と同じにする（無ければ付ける）。
- **ASR の結果が空・他言語・短すぎて捨てた区間も保存する**（「聞き取れなかった」を確かめるのが目的なので）。文字記録の行に `asr_status`
  （ok / empty / other_language / rejected_short / no_party）を足す。輪が無くて ASR に渡さなかった音声は**保存しない**（話し相手でない人の声）。
- エッジ経由（ブラウザから PCM が来る）でもローカルのマイクでも、VAD の出口で同じ関数を通す（保存は 1 か所）。
- 書き込みはターンをブロックしない（別スレッドかキューで）。ディスクが足りないとき（空きが 1GB を切ったら）は保存を止めて WARNING を 1 回。
- 期限: 起動時の掃除に音声も含める。加えて **1 日 1 回（午前 4 時）の掃除**をアプリ内のタイマーで足す（窓口機は何日も起動したままなので起動時だけでは消えない）。
  文字記録・紹介状・小ネタの掃除も同じタイマーに乗せる。「保全」したセッションの音声は文字記録と同じく残す。
- `scripts/export_review.py` には音声を入れない（素材は外に出す前提）。`--with-audio` を付けたときだけ同じフォルダに wav を並べて出す（既定オフ）。

## B. 管理者ページ（`/admin/transcripts/`）

- 各行に ▶（HTML5 audio）。音声は `/admin/transcripts/audio/<date>/<utterance_id>` で配信（Basic 認証・LAN のみ、Range 対応、`Cache-Control: no-store`）。
  `asr_status` が ok 以外の行は印を付けて、ASR が何も返さなかった音声を探しやすくする。
- セッションの画面に「このセッションの来訪者の音声を順に再生」（行をまたいで連続再生。再生中の行を強調）。
- 「保全」はセッション単位で音声にも効く（既存の仕組みに乗せる）。
- 文字記録の一覧に「音声あり／なし」の列と、その日の音声の合計サイズ。

## C. 確認

- テキストモードでは音声が無いので、`--input-wav tests/fixtures/visitor_procedure_ja.wav` で 1 往復 → `audio/` に区間の wav ができ、文字記録の行から辿れる、
  管理者ページで再生できる（curl で 206 が返る）、`IDOBATA_AUDIO_RETENTION_DAYS=0` では何もできない、期限切れが掃除で消える、保全したものは残る、をテスト。
- ディスクの見積もりを結果文書に: 1 発話 5 秒 ≈ 160KB。1 日 200 発話で約 32MB、7 日で約 230MB。
- 紹介状の聞き取りを含む会話を 1 本通し、音声には氏名が入り文字記録では伏せられていることを目で確認（結果文書にはその旨だけ書き、音声の中身は書かない）。
